# 97 Ohm Robotics — сайт команди

Сайт робототехнічної команди «97 Ом» ліцею №97, Дніпро: **https://97ohmrobotics.github.io**

Зроблено на [Astro](https://astro.build): кожен проєкт, допис і учасник — окремий Markdown-файл.
Зміни потрапляють на сайт через pull request: наставник переглядає й зливає, а GitHub Actions за хвилину-дві публікує сайт.

**Як додати проєкт, допис або себе в команду — дивіться [CONTRIBUTING.md](CONTRIBUTING.md).**

## Що де лежить

```
src/content/
  projects/uk/   ← роботи й проєкти
  journal/uk/    ← журнал: змагання, нотатки розробки, новини
  members/uk/    ← учасники команди
  pages/uk/      ← тексти головної та сторінки «Приєднатися» (розклад, контакти)
public/media/    ← фото й схеми (без облич!)
public/brand/    ← логотип і фавікон, не змінювати
src/pages/       ← сторінки сайту (.astro)
src/components/  ← частини сторінок: шапка, штамп, картки
src/styles/global.css ← кольори, шрифти, теми
```

Папка `uk/` потрібна, щоб згодом поруч з'явилася `en/` для англійської версії.

## Запуск на своєму комп'ютері

Потрібен Node.js 24 або новіший.

```sh
npm install
npm run dev       # http://localhost:4321, сайт оновлюється під час редагування
npm run build     # перевірка + збирання в папку dist/
```

Файли з `draft: true` — приклади й чернетки. Їх видно лише в `npm run dev`, на справжній сайт вони не потрапляють.
Коли з'являться справжні проєкти, файли `example-*.md` можна видалити.

## Стиль «Синька»

Сайт виглядає як креслення: сітка, шина NET на головній, роз'єми J1–J5 у меню, учасники — мікросхеми U1, U2…
Світла й темна теми, перемикач у шапці (світла → темна → авто).

Правила бренду (повний брендбук — у наставника):

- Кольори: білий, фіолетовий `#5B2BC4`, чорний `#0E0D12` — смуги резистора 9-7-×1; жовтий `#F5D31B` — допуск, другий акцент.
- Жовтий на світлому фоні — тільки заливкою (кнопка, мітка), ніколи текстом.
- Лінії й рамки не малюємо прямо по сітці, тільки на суцільній панелі.
- Шрифти: Manrope для всього, JetBrains Mono — лише для підписів і даних.
- Знак Ω — тільки в логотипі. У тексті пишемо «97 Ом» або «97 Ohm Robotics».
